항목을 클릭하여 교사 업무에 최적화된 필수 설정 방법을 확인하세요.

Features

General (일반)

브라우저 시작 시 동작과 다운로드 기본 경로를 설정합니다.

✅ 교사 추천 셋팅:
  • `On startup` 옵션을 'Continue where you left off' (이전 탭 유지)로 설정하세요. 퇴근 후 다음날 나이스, 업무포털 탭이 그대로 유지됩니다.

Appearance (화면 테마 및 크기)

💡 꿀팁: 교실 전자칠판 연결 시 Page Zoom을 125% 이상으로 설정하면 맨 뒷자리의 학생들도 글씨를 명확하게 볼 수 있습니다.

Security & Privacy

❗ 공용 PC 주의사항: 교무실 공용 PC에 설치했다면 '브라우저 종료 시 쿠키 삭제' 옵션을 활성화하여 개인정보를 보호하세요.

Agents (나만의 AI 비서)

업무 목적별 커스텀 에이전트를 만듭니다. 예: '학생부 도우미', '번역기' 등.

🌟 Models (AI 두뇌 선택 - 핵심)

에이전트가 사용할 인공지능 모델(두뇌)을 결정합니다.

  • Claude 3.5 Sonnet (추천): 공문서 요약, 표 정리, 자연스러운 한국어에 가장 뛰어납니다.
  • GPT-4o: 웹 검색 연동이 강력하여, 수업 자료 리서치나 빠른 답변에 적합합니다.
  • BYOK: API Key를 직접 발급받아 입력하면 매우 저렴하게 무제한 사용 가능합니다.

💡 Context Awareness (상황 인지 - 필수)

현재 화면에 띄워진 웹페이지를 AI가 실시간으로 파악하는 핵심 기능입니다.

이 기능을 ON으로 켜두어야 "이 페이지 요약해줘" 명령이 가능합니다. 무조건 활성화하세요.

Passwords (비밀번호 권한)

AI가 나이스(NEIS) 등에 대신 로그인할 수 있도록 비밀번호를 연동합니다. (지문/얼굴 인식 필수)

Mini popup (빠른 실행)

우측 패널을 열지 않고도 화면 중앙에 명령창을 띄우는 단축키입니다. (기본: Mac Cmd+K, Win Ctrl+K)

기초: 현재 페이지 읽고 요약하기

긴 공문이나 지침서를 에이전트가 읽고 요약하게 합니다. 순서대로 따라해보세요.

실습 긴 연수 공문서, 3줄 핵심 요약하기

1

공문 페이지 열기

업무포털이나 학교 홈페이지에서 내용이 긴 공문 페이지를 화면에 띄웁니다.

2

Aside 패널 열기

브라우저 우측 상단 [A] 아이콘을 클릭하거나 단축키 Ctrl+Shift+Space를 누릅니다.

3

명령: 프롬프트 입력 및 실행 여기서 직접 해보세요!

아래 박스 안의 [복사] 버튼을 클릭하고 우측 입력창에 붙여넣어(Ctrl+V) 전송해보세요.

이 공문의 1)목적, 2)신청 대상(자격), 3)신청 마감 기한, 4)주요 연수 내용을 3줄 이내로 매우 간결하게 요약해줘. 그리고 내가 다운로드해서 제출해야 할 첨부파일 양식이 있다면 그 목록도 빼놓지 말고 알려줘.

심화: 여러 탭 모아 표 만들기

Aside는 상단에 열려있는 여러 개의 탭을 스스로 넘나들며 자료를 모으고 비교해줍니다.

실습 3개의 에듀테크 사이트 비교표 만들기

1

상단에 여러 탭 띄우기

예: [첫번째 탭: 패들렛], [두번째 탭: 띵커벨], [세번째 탭: 캔바]

2

프롬프트 복사 및 붙여넣기

AI가 스스로 탭을 이동하는 시뮬레이션을 볼 수 있습니다.

현재 열려있는 3개의 에듀테크 서비스 홈페이지 탭을 각각 방문해서 탐색해줘. 각 서비스의 정보를 종합해서 아래 항목을 기준으로 깔끔한 마크다운 표(Table)로 작성해줘.
[표 구분 항목] : 서비스명 / 주요 기능 3가지 / 교사 인증 시 무료 혜택 / 학생 회원가입 필수 여부

응용: 캔바(Canva) 자료 자동 생성

AI가 웹페이지를 분석하여 카드뉴스 기획안을 짜고, 캔바 홈페이지를 스스로 열어 템플릿 검색까지 완료합니다.

실습 텍스트 교육 자료를 5장짜리 카드뉴스로 재구성하기

1

변환할 긴 교육 자료 열기

학생들에게 가르칠 내용이 담긴 긴 웹페이지(예: 사이버 폭력 예방 수칙)를 브라우저에 띄웁니다.

2

카드뉴스 기획 및 캔바 자동 실행

AI가 초안을 짜고 새 탭에서 캔바 검색까지 대신 실행합니다.

현재 열려있는 웹페이지의 내용을 분석해서, 학생 교육용 캔바(Canva) 카드뉴스(또는 프레젠테이션) 5장 분량의 초안을 기획해줘. 각 장마다 [슬라이드 제목 / 핵심 내용 2줄 요약 / 어울리는 시각 자료 추천]을 마크다운으로 깔끔하게 정리해줘.

내용 정리가 끝나면, 새 탭에서 캔바 홈페이지(canva.com)를 열고 중앙 검색창에 '교육용 카드뉴스'라고 타이핑한 뒤 엔터를 쳐서 템플릿 검색까지 대신 실행해줘.

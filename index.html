핵심 설정 가이드 (Settings 메뉴 정복)

브라우저 우측 상단의 톱니바퀴 아이콘을 클릭하여 진입하는 Settings 메뉴의 완벽 가이드입니다.
좌측 메뉴를 하나씩 클릭하여 교사 업무에 최적화된 필수 설정 방법과 설명을 확인하세요.

General (일반)

브라우저의 시작 페이지 동작과 다운로드 기본 경로를 설정합니다.

✅ 교사 추천 셋팅:
  • `On startup` 옵션을 'Continue where you left off' (이전 작업 탭 유지)로 설정하세요. 퇴근 시 브라우저를 닫아도 다음날 나이스, 업무포털 탭이 그대로 열립니다.

Appearance (화면 테마 및 크기)

라이트/다크 모드, 글꼴 크기, 전체 페이지 줌 배율을 설정합니다.

💡 꿀팁: 교실 전자칠판 연결 시 Page Zoom을 125% 이상으로 설정하면 맨 뒷자리에 앉은 학생들도 글씨를 명확하게 볼 수 있습니다.

Account (계정)

현재 로그인된 계정 정보를 관리하고, 즐겨찾기(북마크) 및 확장프로그램 동기화 여부를 설정합니다.

Plan & Usage (요금 및 크레딧)

현재 이용 중인 요금제와 AI 모델별 API 호출량(크레딧) 사용 내역을 실시간으로 확인합니다.

Security & Privacy

에이전트가 선생님의 브라우징 데이터를 수집하거나 학습하는 것을 제어합니다.

❗ 교무실 공용 PC 주의사항: 학교 공용 PC에 설치하셨다면 반드시 '브라우저 종료 시 쿠키 및 사이트 데이터 삭제' 옵션을 활성화하여 개인정보 유출을 방지하세요.

Agents (나만의 AI 비서 만들기)

업무 목적별로 프롬프트가 사전 세팅된 커스텀 에이전트를 관리합니다.
예: '학생부 행동특성 도우미', '가정통신문 영어 번역기' 등을 만들어두면 매번 지시할 필요가 없습니다.

Projects (프로젝트 단위 작업)

체육대회 기획, 학부모 총회 준비 등 관련된 여러 탭과 문서를 하나의 '프로젝트' 폴더로 묶습니다. AI가 해당 프로젝트 내의 맥락만 집중적으로 분석하게 됩니다.

🌟 Models (AI 두뇌 선택 - 매우 중요)

우측 패널의 에이전트가 실제로 사용할 인공지능 모델(두뇌)을 결정합니다. 작업의 난이도에 따라 전환하며 사용하세요.

  • Claude 3.5 Sonnet (교사 강력 추천): 공문서 요약, 복잡한 표 정리, 자연스러운 한국어 작성에 현재 가장 뛰어난 성능을 보입니다.
  • GPT-4o: 속도가 매우 빠르고 웹 검색 연동이 강력하여, 수업 자료 리서치나 빠른 답변이 필요할 때 적합합니다.
  • BYOK (Bring Your Own Key): API Key를 직접 발급받아 입력하면 요금제 제한 없이 매우 저렴하게 무제한 사용이 가능합니다. (이후 Developers 메뉴 연동)

Plugins & MCPs (외부 앱 연동)

구글 드라이브(Google Workspace), 노션(Notion) 등과 연동하여 AI가 선생님의 구글 문서를 직접 읽고 수정하도록 권한을 부여합니다.

Memory (에이전트 기억력)

AI에게 "내 이름은 김병찬이고, 미래초등학교 5학년 2반 담임이야"라고 입력해두면, 이후 공문이나 가정통신문을 작성할 때 매번 소속을 말하지 않아도 알아서 기입해 줍니다.

💡 Context Awareness (상황 인지 - 필수 켜기)

현재 화면에 띄워진 웹페이지나 문서의 내용을 AI가 실시간으로 파악하는 Aside의 핵심 기능입니다.

이 기능을 ON으로 켜두어야, "이 페이지 요약해줘", "방금 본 표를 엑셀로 바꿔줘" 같은 명령이 가능합니다. 무조건 활성화 상태를 유지하세요.

Passwords (비밀번호 및 권한)

AI가 나이스(NEIS)나 연수원 사이트에 대신 로그인하여 작업을 수행할 수 있도록 크롬 비밀번호를 연동합니다. (지문/얼굴 인식 등 OS 생체인증이 필수적으로 요구됩니다.)

Routines (반복 업무 스케줄링)

"매주 월요일 아침 8시 40분에 교육청 새 공문을 확인해서 나에게 요약해줘" 와 같은 예약 스케줄을 만들고 관리합니다.

Channels (알림 연동)

에이전트가 처리한 업무 결과(예: 설문조사 취합 완료)를 학교 쿨메신저, 슬랙, 팀즈 등으로 바로 전송하도록 웹훅(Webhook)을 연결합니다.

Developers (고급 개발자 모드)

로컬 컴퓨터(선생님의 PC 바탕화면 등)에 파일을 직접 쓰고 읽을 수 있는 권한을 설정하거나, 외부 API를 연결하는 전문가용 설정입니다.

Mini popup (빠른 실행 단축키)

우측의 무거운 패널을 열지 않고도 화면 중앙에 작고 빠른 명령창(Spotlight 형태)을 띄우는 단축키를 설정합니다. (기본값: Mac Cmd+K, Win Ctrl+K)

Lasso (화면 캡처 올가미 툴)

화면 전체가 아닌 원하는 특정 영역(예: 복잡한 급식 식단표 일부)만 마우스로 드래그하여 AI에게 바로 전송하는 단축키를 설정합니다.

Archived chats (보관된 대화)

종료되거나 보관 처리한 과거 AI와의 대화 기록을 검색하고, 필요시 다시 불러와 작업을 이어갈 수 있습니다.

기초 실습: 현재 페이지 완벽하게 읽고 요약하기

가장 기본적이면서 교사들이 매일 쓰는 기능입니다. 화면에 띄운 긴 교육청 공문이나 지침서를 에이전트가 읽고 요약하게 합니다. 아래의 단계(Step)를 순서대로 클릭하고 따라해보세요.

실습 긴 연수 공문서, 3줄 핵심 요약하기

1

준비: 공문 페이지 열기

업무포털(K-에듀파인)이나 학교 홈페이지에 접속하여 내용이 긴 연수 안내문이나 공문 페이지를 클릭하여 화면에 띄웁니다. (현재 이 창을 공문이라고 가정하셔도 좋습니다.)

2

호출: Aside 패널 열기

브라우저 우측 상단 확장프로그램 영역에 있는 보라색 [A] 아이콘을 클릭합니다.
또는 키보드 단축키 Ctrl + Shift + Space (Mac은 Cmd)를 누르면 우측에 AI 채팅창이 열립니다.

3

명령: 프롬프트 입력 및 실행 여기서 직접 해보세요!

1. 아래 검은색 박스 우측의 [복사] 버튼을 클릭합니다.
2. 우측 화면 아래쪽의 텍스트 입력창(Ask AI a task...)을 클릭하고 붙여넣기(Ctrl+V) 합니다.
3. 키보드 엔터(Enter) 또는 입력창 우측 화살표(전송) 버튼을 클릭합니다.

이 공문의 1)목적, 2)신청 대상(자격), 3)신청 마감 기한, 4)주요 연수 내용을 3줄 이내로 매우 간결하게 요약해줘. 그리고 내가 다운로드해서 제출해야 할 첨부파일 양식이 있다면 그 목록도 빼놓지 말고 알려줘.

심화 실습: 여러 탭의 정보를 모아 표(Table)로 만들기

Aside의 강력한 장점은 현재 탭 하나만 읽는 것이 아니라, 상단에 열려있는 여러 개의 탭을 스스로 넘나들며 자료를 모으고 비교해준다는 점입니다.

실습 3개의 에듀테크 사이트 가격/기능 전격 비교표 만들기

1

준비: 상단에 여러 탭 띄우기

브라우저 맨 위 탭에 비교하고 싶은 사이트들을 엽니다.
예시: [첫번째 탭: 패들렛 홈페이지], [두번째 탭: 띵커벨 홈페이지], [세번째 탭: 캔바 홈페이지]

2

명령: 프롬프트 복사 및 붙여넣기

아래 프롬프트를 복사하여 우측 채팅창에 붙여넣고 전송해보세요. AI가 스스로 탭을 이동하는 시뮬레이션을 볼 수 있습니다.

현재 열려있는 3개의 에듀테크 서비스 홈페이지 탭을 각각 방문해서 탐색해줘. 각 서비스의 정보를 종합해서 아래 항목을 기준으로 깔끔한 마크다운 표(Table)로 작성해줘.
[표 구분 항목] : 서비스명 / 주요 기능 3가지 / 교사 인증 시 무료 혜택 / 학생 회원가입 필수 여부

응용 실습: 긴 웹문서를 캔바(Canva) 카드뉴스/프레젠테이션으로 변환하기

단순히 페이지를 읽는 것을 넘어, AI가 선생님을 대신하여 자료를 특정 시각화 포맷으로 기획하고, 다른 웹사이트(캔바)를 직접 제어하는(Action) 과정입니다. 방대한 교육 자료를 학생용 시각 자료로 빠르게 바꿀 때 매우 유용합니다.

실습 텍스트 기반 교육 자료를 5장짜리 시각 자료로 재구성하기

1

준비: 변환할 긴 교육 자료 웹페이지 열기

학생들에게 가르치고자 하는 내용이 담긴 긴 웹페이지(예: 안전교육 가이드라인 뉴스 기사, 사이버 폭력 예방 수칙 등)를 브라우저에 띄웁니다.

2

명령: 카드뉴스 기획 및 캔바 자동 실행 프롬프트

AI가 현재 페이지를 읽어 초안을 짜고 -> 새 탭에서 캔바를 열어 -> 템플릿 검색까지 완료하는 통합 프롬프트입니다.

현재 열려있는 웹페이지의 내용을 분석해서, 학생 교육용 캔바(Canva) 카드뉴스(또는 프레젠테이션) 5장 분량의 초안을 기획해줘. 각 장마다 [슬라이드 제목 / 핵심 내용 2줄 요약 / 어울리는 시각 자료 추천]을 마크다운으로 깔끔하게 정리해줘.

내용 정리가 끝나면, 새 탭에서 캔바 홈페이지(canva.com)를 열고 중앙 검색창에 '교육용 카드뉴스'라고 타이핑한 뒤 엔터를 쳐서 템플릿 검색까지 대신 실행해줘.
